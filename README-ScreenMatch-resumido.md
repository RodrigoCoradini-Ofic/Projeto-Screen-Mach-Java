# 🎬 ScreenMatch

Projeto desenvolvido em **Java** para praticar **Programação Orientada a Objetos**, utilizando filmes, séries e episódios como exemplo.

## 🛠️ Tecnologias

- Java
- Maven
- Gson
- JSON

## 📌 Conceitos praticados

- Classes e objetos
- Herança e polimorfismo
- Interfaces
- Encapsulamento
- `ArrayList`
- `Comparable`
- `record`
- Exceções personalizadas
- Manipulação de JSON

## 📂 Estrutura

```text
src/
└── br/com/alura/ScreenMatch/
    ├── principal/
    ├── modelos/
    ├── calculos/
    ├── buscas/
    ├── arquivos/
    └── excessoes/
```

## ▶️ Executando

Clone o projeto:

```bash
git clone https://github.com/RodrigoCoradini-Ofic/Projeto-Screen-Mach-Java.git
```

Compile com Maven:

```bash
mvn compile
```

Execute a classe:

```text
br.com.alura.ScreenMatch.principal.Principal
```

## 🎯 Objetivo

Projeto de estudos para desenvolver conhecimentos em **Java, POO, APIs, JSON e organização de projetos com Maven**.
